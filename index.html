Armazenamento no Google Drive

Os dados são mantidos offline neste dispositivo e sincronizados em uma planilha dentro da pasta escolhida.

O ID OAuth é público (não cole segredos). A autorização é solicitada pelo Google e o token fica apenas na memória desta sessão.

Como configurar o acesso no Google Cloud
  1. No Google Cloud Console, selecione ou crie um projeto e habilite Google Drive API e Google Sheets API.
  2. Configure a tela de consentimento OAuth e, se o app estiver em modo de teste, adicione sua conta Google como usuária de teste.
  3. Crie uma credencial OAuth do tipo Aplicativo da Web; em “Origens JavaScript autorizadas”, cadastre a origem HTTPS onde este app está publicado (e http://localhost para desenvolvimento local).
  4. Copie o ID do cliente OAuth para o campo acima. Não use nem compartilhe um client secret.
  5. Crie/abra uma pasta no Drive da mesma conta Google e cole aqui o link. O app criará nela a planilha “Atelie Manager”.
