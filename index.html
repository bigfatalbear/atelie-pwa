Sincronização segura com Supabase

Os dados permanecem neste dispositivo para uso offline e são sincronizados na sua conta Supabase quando houver internet.

Projeto configurado: nbekjeuadgiscrsgygyj.supabase.co. A chave publishable é pública; a segurança depende do login e das políticas RLS. Nenhuma chave secreta é usada pelo app.

Conta conectada:
Sobre a configuração do Supabase
  1. O app já vem apontado para o projeto atelie-pwa; URL e chave publishable são incluídas como configuração pública do frontend.
  2. O esquema e as políticas RLS são definidos em supabase/setup.sql. Nunca use a chave secret ou service_role neste app.
  3. Crie sua conta e confirme o e-mail enviado pelo Supabase antes de entrar. Use a mesma conta em outros dispositivos.
  4. Os dados locais não são apagados ao sair. Se houver divergência, escolha explicitamente qual cópia manter; o app cria um backup antes de substituir dados.
